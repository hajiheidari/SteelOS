# وضعیت ایجنت‌های SteelOS

این گزارش وضعیت پیاده‌سازی را از برنامهٔ آینده جدا می‌کند. در وضعیت فعلی هیچ ایجنت
متصل به مدل زبانی، worker خودمختار یا کانال پیام‌رسان فعال نیست. APIهای دامنه و رابط
انسانی آماده‌اند؛ وجود آن‌ها به معنی آماده‌بودن ایجنت هوش مصنوعی نیست.

| قابلیت | وضعیت فعلی | کار باقی‌مانده برای ایجنت |
| --- | --- | --- |
| دستیار فروش | کاتالوگ، CRM، قیمت معتبر، draft، محاسبات مالی و بازبینی داخلی پیاده شده | adapter مدل، هویت/اختیار محدود ایجنت، ابزارهای مجاز، تست hallucination و پیشنهاد قابل تأیید |
| جمع‌آوری قیمت | ورود دستی و provider محلی mock از API کنترل‌شده کار می‌کند | منابع واقعیِ مجاز و adapter آن‌ها؛ mock ایجنت هوشمند نیست |
| OCR فاکتور | پیاده نشده | intake سند، parser/OCR، ارزیابی کیفیت و تأیید انسانی |
| تحقیق بازار و کشف مشتری | برنامه‌ریزی‌شده | منابع مجاز، شواهد، کنترل هزینه و ارزیابی خروجی |
| بازاریابی و پیام‌رسان‌ها | برنامه‌ریزی‌شده؛ هیچ اتصال یا ارسال فعالی نیست | مجوز کانال/ارسال، سیاست محتوا و اتصال کنترل‌شده |
| حسابداری هوشمند | برنامه‌ریزی‌شده؛ موتور حسابداری عملیاتی نداریم | invariants دفتر دوطرفه، تطبیق موازی و سپس ابزارهای محدود |

## ترتیب اجرای ایمن دستیار فروش

1. پاسخ و جست‌وجوی فقط‌خواندنی با ارجاع به دادهٔ همان سازمان و قیمتِ دارای زمان اعتبار.
2. تولید پیشنهاد داخلی با schema معتبر و API دامنه؛ مدل منبع حقیقت قیمت/مالیات/موجودی نیست.
3. بازبینی انسانی نسخهٔ مشخص سند؛ تغییر نسخه یا انقضای قیمت باید دوباره بررسی شود.
4. صدور/ارسال مشتری فقط پس از پیاده‌سازی گذار مستقل و اختیار صریح؛ بازبینی داخلی آن را انجام نمی‌دهد.

انتخاب/اتصال مدل و runtime هنوز انجام نشده است. زیرساخت پولی یا API پولی اجباری نداریم؛
انتخاب بعدی باید هزینه، امکان اجرای محلی، کیفیت فارسی و محدودیت داده را ارزیابی کند.
هویت ایجنت و allowlist ابزارها هنوز قابلیت پیاده‌شده نیستند؛ کلید admin انسانی نباید
به‌عنوان هویت ایجنت استفاده شود. ایجنت نباید مستقیم در ledger، مالکیت یا قیمت مصوب بنویسد.
