# وضعیت ایجنت‌های SteelOS

نسخهٔ اول **دستیار جست‌وجوی فروش فقط‌خواندنی** پیاده شده و با مدل محلی واقعی آزمایش
شده است. این یک دستیار محدود برای تشخیص نام کالا/ارز و نمایش شواهد قیمت از API است؛
فروش خودمختار، صدور پیش‌فاکتور، بازاریابی یا پیام‌رسانی انجام نمی‌دهد.

| قابلیت | وضعیت فعلی | کار باقی‌مانده |
| --- | --- | --- |
| دستیار جست‌وجوی فروش | مدل محلی Qwen از طریق Ollama، APIهای فقط‌خواندنی محدود، رابط فارسی، فیلتر دقیق ابعاد و آزمون واقعی آمادهٔ تست داخلی محلی | ارزیابی گسترده‌تر فارسی/بار، ابعاد/قواعد زبانی بیشتر، workflow پیشنهاد قابل تأیید |
| ساخت/بازبینی draft | API و رابط انسانی با تاریخچه و محاسبات دو اعشاری آماده است | دستیار فعلی اختیار نوشتن یا بازبینی ندارد؛ مسیر پیشنهادی ایجنت هنوز اجرا نشده |
| جمع‌آوری قیمت | ورود دستی و provider محلی mock از API کار می‌کند | منابع واقعیِ مجاز و adapter آن‌ها؛ mock ایجنت هوشمند نیست |
| OCR فاکتور | پیاده نشده | intake، OCR/parser، ارزیابی کیفیت و تأیید انسانی |
| تحقیق بازار و کشف مشتری | برنامه‌ریزی‌شده | منابع مجاز، شواهد، کنترل هزینه و ارزیابی خروجی |
| بازاریابی و پیام‌رسان‌ها | برنامه‌ریزی‌شده؛ هیچ اتصال/ارسالی فعال نیست | مجوز کانال/ارسال و اتصال کنترل‌شده |
| حسابداری هوشمند | برنامه‌ریزی‌شده؛ موتور حسابداری عملیاتی نداریم | دفتر دوطرفه، تطبیق موازی و ابزارهای محدود |

## وضعیت دقیق اتصال مدل

- اتصال اختیاری Ollama/Qwen محلی پیاده و آزموده شد؛ به‌صورت پیش‌فرض disabled است و
  سرویس پولی یا کلید API لازم ندارد. در همین محیط توسعه مدل رایگان محلی اجرا شد.
- مدل فقط نام جست‌وجو/ارز استخراج می‌کند؛ قیمت، واحد، منشأ و اعتبار از API همان سازمان
  می‌آیند. خروجی آزاد مدل به‌عنوان واقعیت مالی نمایش داده نمی‌شود.
- ابزارها فقط catalog.search و prices.current هستند؛ مدل توکن، دسترسی DB، سازمان انتخابی،
  ابزار ثبت/تأیید/ارسال یا سابقهٔ مکالمه ندارد. دسترسی، واگذاری محدود فقط‌خواندنی از نشست
  کاربر است؛ service principal مستقل ایجنت هنوز ساخته نشده است.
- ۱۲ سناریوی مصنوعی (شامل ابعاد و ابهام) و آزمون API با تطبیق واحد، پس از اصلاح دو خطای املای مدل موفق شدند. شواهد اولیهٔ ۱۰/۱۲ و نهایی ۱۲/۱۲ حفظ شده‌اند.
- ۷ سناریوی اولیهٔ فارسی و تست API با مدل واقعی موفق شدند. این ارزیابی کوچک به معنی
  کیفیت عمومی، آمادگی production یا پایان پروژه نیست. CI از fixture مدل محلی برای تکرارپذیری
  استفاده می‌کند؛ fixture به‌عنوان مدل واقعی معرفی نمی‌شود.

راه‌اندازی، محدودیت‌ها و آزمون‌ها در [SALES_ASSISTANT.md](SALES_ASSISTANT.md) هستند.
هیچ deployment عمومی، سرویس پولی یا ارسال مشتری انجام نشده است.

The local read-only assistant additionally supports explicit numeric inclusive dimension
ranges (از…تا / بین…و) and displays both bounds. Real local synthetic extraction evaluation
matched14/14 including a valid and reversed range. This is a small regression set, not a
production-language or throughput benchmark; open/exclusive and number-word ranges remain
unsupported. No new model tools or write permissions were added.
