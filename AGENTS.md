# SteelOS development rules

- Work only on feature branches and use pull requests; never push development directly to main.
- No paid APIs, services, hosting, deployment, or public publishing without founder approval.
- Persian RTL UI; preserve organization boundaries and auditability.
- Monetary values and weights use Decimal/NUMERIC, never floating-point.
- Financial, stock ownership, price approval and tax decisions require deterministic validations.
- Add tests and update docs/DEVELOPMENT_STATUS.md for every milestone.
- Never commit secrets or real customer data.
